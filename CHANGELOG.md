# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial release of BlazorSupercookie
- `FingerprintEngine` - Core engine for fingerprint operations
- `FingerprintService` - Thread-safe service for managing sessions
- `FingerprintSession` - Session management for fingerprinting
- `SupercookieComponent` - Blazor component with JS interop
- Comprehensive unit tests
- Demo Blazor WebAssembly application
- Backend API for favicon serving
- GitHub Actions workflows for CI/CD
- GitHub Pages deployment workflow
- NuGet package configuration
- Comprehensive documentation

### Features
- High-performance, zero-allocation fingerprinting engine
- Thread-safe implementation using modern C# patterns
- Beautiful, responsive Blazor component
- Full support for read and write modes
- Progress indicators and error handling
- Production-ready NuGet package
